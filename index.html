Régimes & allergies

Nombre de personnes concernées, par section (pour le camp en cours). L'appli retire l'ingrédient pour elles et ajoute le substitut à acheter.

✏️ Modifier / ajouter des régimes et allergies

Pour chaque ingrédient concerné : le remplacer par un substitut, ou le retirer.

⚠️ Vérifie toujours les étiquettes (traces possibles) et confirme les allergies graves avec les parents.

Menu du camp

Les jours viennent des dates du camp. Glisse ⠿ pour déplacer un plat d'un repas ou d'un jour à l'autre. Clique sur le nom d'un repas (Matin, Midi…) pour le renommer, changer sa couleur, le monter ou le descendre (ou glisse son ⠿), ou le retirer.

Recettes

Sur la page d'une recette, ouvre le code source (clic droit → « Afficher le code source »), cherche ld+json et colle ici le bloc <script type="application/ld+json">…</script> qui contient « Recipe ». Si la page n'a pas de bloc « Recipe » (article, site sans données structurées), copie plutôt la liste des ingrédients, une ligne par ingrédient. L'appli ne lit que ce que tu colles, elle n'appelle aucun site.

Touche une recette pour la modifier : nom, types et mots-clés, description, ingrédients et quantités.

Catalogue de prix

Tape le prix directement dans le tableau ci-dessous (ou dans la liste de courses), ou importe des prix : un fichier, la dernière collecte publiée, ou une liste collée.

Importer des prix

À quoi ça sert ? À remplir les prix sans les taper un par un. Importe une liste de produits d'un magasin : une ligne par produit, nom ; prix. L'appli lit le poids dans le nom (« Riz 1kg ; 1,95 » → 1,95 €/kg) et prend, pour chaque ingrédient, le produit le moins cher qui correspond. Un fichier .json de prix (collecte) est lu tel quel.

Doublons dans le catalogue

Des ingrédients qui portent le même nom (accents, majuscules et pluriel ignorés) et la même unité. Choisis lequel garder : les quantités des recettes sont additionnées, le prix est repris si l'ingrédient gardé n'en a pas.

Fusionner deux ingrédients

Les quantités des recettes sont additionnées, le prix est repris si l'ingrédient gardé n'en a pas. L'ingrédient supprimé disparaît du catalogue et des recettes.

Modifier la recette

Description / déroulé
Sélectionne des mots puis clique sur G (gras), S (souligné) ou I (italique).
Aperçu avec la mise en forme :

Quantité par personne et par section (g, ml ou pièces). Pour une quantité unique (ex. 5 pains, 5 L de lait), clique sur le nom de l'ingrédient pour ouvrir sa fiche, puis sur « → quantité unique ». Elle est répartie au prorata des régimes (désactivable).

Les prix, noms et unités modifiés dans la fiche d'un ingrédient sont ceux du catalogue : ils restent même si tu annules.

Gérer les rayons

Les rayons sont les mêmes pour tous les camps. Renommer un rayon garde ses produits. L'ordre est celui de la liste de courses et des exports. « Autre » est le rayon de secours : il reste toujours.
