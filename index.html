Catalogue de prix

À quoi ça sert ? À remplir les prix sans les taper un par un. Deux façons, au choix (aucune n'est obligatoire) :

① Tape le prix directement dans le tableau ci-dessous (ou dans la liste de courses).
② Importe une liste de produits d'un magasin : une ligne par produit, nom ; prix. L'appli lit le poids dans le nom (« Riz 1kg ; 1,95 » → 1,95 €/kg) et prend, pour chaque ingrédient, le produit le moins cher qui correspond.
